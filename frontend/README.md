# Frontend

React web application with Tailwind CSS styling.

## Features
- User authentication
- Dashboard with statistics
- Word set management
- Multiple learning modes
- Word import interface
- Responsive design

## Setup

1. Install dependencies: `npm install`
2. Run development server: `npm start`

App runs on `http://localhost:3000`

## Components
- `AuthForm` - Login/registration
- `Dashboard` - Main dashboard with stats
- `FlashCard` - Flashcard component
- `ReviewModes` - Learning mode selector
- `ImportWords` - Word import interface
